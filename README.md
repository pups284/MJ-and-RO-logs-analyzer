# 🎮 Majestic Log Analyzer

**Десктопный анализатор логов для лаунчера Majestic RP / Россия Онлайн**

Приложение помогает технической поддержке быстро находить причины проблем игроков в логах `main.log`, `client.log`, `patcher.log` и мгновенно получать готовый ответ для игрока.

## ✨ Возможности

- 📦 **Удобная установка**: инсталлятор создаёт ярлыки, добавляет программу в систему и ассоциирует файлы `.log`. Поддерживает 3 языка на выбор (RU / EN / UA).
- 📂 **Интеграция с Проводником**: просто дважды кликните по `.log` файлу или перетащите его на иконку программы, чтобы мгновенно начать анализ.
- 🛡 **Single Instance**: если приложение уже запущено, новый лог откроется в текущем окне, а оно выйдет на передний план.
- 🔍 **Умный анализ**: ищет ошибки по правилам (allOf/anyOf/noneOf, regex, кастомные проверки), учитывает контекст и метаданные (платформа, сервер, пути).
- 🧩 **Мощный редактор**: открывает логи в отдельных независимых окнах. Поддерживает подсветку синтаксиса, нумерацию строк, миникарту и поиск по `Ctrl+F`.
- 🔄 **Гибкая синхронизация**: каждая вкладка («Правила», «Примечания», «Исключения») может независимо обновляться из GitHub.
- 🎨 **Комфортная работа**: светлая и тёмная темы, а также встроенный пошаговый туториал с подсветкой элементов интерфейса для быстрого старта.

## 💾 Где хранятся данные

Все пользовательские настройки, правила и примечания хранятся в папке `%APPDATA%`:
`%appdata%\MajesticLogAnalyzer\data\`

Основные файлы:
- `rules.json` — правила анализа
- `notes.json` — примечания к правилам
- `exceptions.json` — исключения (скрытые находки)
- `ui.json` — настройки интерфейса (тема, положение окон)
- `settings.json` — системные настройки

*Примечание: При удалении программы через установщик папка с данными в `%APPDATA%` не удаляется, чтобы сохранить ваши наработки.*

## 🚀 Запуск из исходников

Требуется **Python 3.10+**.

```bash
git clone https://github.com/pups284/MJ-and-RO-logs-analyzer
cd MJ-and-RO-logs-analyzer

python -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate      # Linux / macOS

pip install -r requirements.txt
python main.py
```
