# 🎮 Majestic Log Analyzer

**Десктопный анализатор логов для лаунчера Majestic RP / Россия Онлайн**

Приложение помогает технической поддержке быстро находить причины проблем игроков в логах `main.log`, `client.log`, `patcher.log` и мгновенно получать готовый ответ для игрока.

## ✨ Возможности

- 📦 **Готовый установщик**: создаёт ярлыки, прописывает ассоциацию файлов `.log` и добавляет программу в «Установку и удаление программ». При деинсталляции корректно удаляет папку с программой.
- 📂 **Интеграция с Проводником**: просто дважды кликните по `.log` файлу или перетащите его на иконку `.exe`, и он откроется в программе для анализа.
- 🛡 **Single Instance**: если программа уже запущена, новый лог откроется в текущем окне, а оно выйдет на передний план.
- 🔍 **Умный анализ**: ищет ошибки по правилам (allOf/anyOf/noneOf, regex, кастомные проверки), учитывает контекст и метаданные (платформа, сервер, пути).
- 🧩 **Встроенный редактор**: открывает лог целиком с подсветкой синтаксиса, нумерацией строк и миникартой (как в Sublime Text). Поддерживает Ctrl+F и создание правил прямо из выделенного текста.
- 🚫 **Раздельные базы**: примечания и исключения (скрытие ложных срабатываний) хранятся в разных файлах и имеют отдельные интерфейсы управления.
- 🔄 **Изолированная синхронизация**: каждая вкладка («Правила», «Примечания», «Исключения») может независимо обновляться из GitHub.
- 💾 **Безопасное хранение**: база правил, примечаний и настроек хранится в `%APPDATA%`, поэтому переустановка или обновление программы не затирает ваши данные.

## 💾 Где хранятся данные

При первом запуске программа создаёт папку для пользовательских данных:
`C:\Users\<Имя>\AppData\Roaming\MajesticLogAnalyzer\data\`

В ней лежат:
- `rules.json` — правила анализа
- `notes.json` — примечания к правилам
- `exceptions.json` — исключения (скрытые находки)
- `ui.json` — настройки интерфейса
- `settings.json` — сохранённые токены (например, для импорта из Discord)

**Важно:** приложение больше не восстанавливает правила и примечания из вшитых резервов. Если вы удалите `rules.json` или `notes.json`, программа стартует с пустой базой. Для сброса к стандартным настройкам используйте кнопку «Обновить из GitHub». При удалении программы через установщик папка с данными в `%APPDATA%` **не удаляется**, чтобы вы не потеряли свои наработки.

## 🚀 Запуск из исходников

Требуется **Python 3.10+**.

```bash
git clone https://github.com/pups284/MJ-and-RO-logs-analyzer
cd MJ-and-RO-logs-analyzer

python -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate      # Linux / macOS

pip install -r requirements.txt
python main.py
